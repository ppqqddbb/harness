# 🔧 安装问题故障排除

## 问题：bcrypt 构建脚本被阻止

你遇到的错误：
```
[ERR_PNPM_IGNORED_BUILDS] Ignored build scripts: bcrypt@5.1.1
Run "pnpm approve-builds" to pick which dependencies should be allowed to run scripts.
```

**原因**：`bcrypt` 是一个原生 C++ 模块，需要在 Windows 上编译。pnpm 出于安全考虑默认阻止了构建脚本。

---

## ✅ 解决方案（3 个方法，按推荐顺序）

### 方法 1: 允许 bcrypt 构建（推荐）

```bash
cd D:\File\VSCodeFile\QDHB\deepseek-harness

# 1. 允许 bcrypt 运行构建脚本
pnpm config set enable-pre-post-scripts true

# 2. 或者使用 approve-builds（更安全）
pnpm approve-builds

# 3. 重新安装
pnpm install --force

# 4. 构建项目
pnpm run build

# 5. 创建管理员账号（使用项目内的 CLI）
./node_modules/.bin/dsh auth create-user admin Admin@2024 --admin

# 6. 启动系统
pnpm dsh web
```

**注意**：如果你的 Windows 系统没有安装 Visual Studio Build Tools，bcrypt 可能仍然无法编译。

---

### 方法 2: 使用 bcryptjs（纯 JavaScript，无需编译）⭐

这是**最简单、最可靠**的方法，不需要任何 C++ 编译工具。

#### 步骤 1: 修改依赖

```bash
cd D:\File\VSCodeFile\QDHB\deepseek-harness

# 进入 auth-local 目录
cd packages/auth/auth-local

# 移除 bcrypt
pnpm remove bcrypt @types/bcrypt

# 安装 bcryptjs
pnpm add bcryptjs
pnpm add -D @types/bcryptjs

# 返回项目根目录
cd ../../..
```

#### 步骤 2: 修改代码

编辑 `packages/auth/auth-local/src/index.ts`，将第 10 行：

```typescript
// 修改前
import bcrypt from 'bcrypt'

// 修改后
import bcrypt from 'bcryptjs'
```

**就这一行！** bcryptjs 的 API 与 bcrypt 完全兼容，其他代码无需修改。

#### 步骤 3: 继续安装

```bash
# 安装所有依赖
pnpm install

# 构建项目
pnpm run build

# 创建管理员
./node_modules/.bin/dsh auth create-user admin Admin@2024 --admin

# 启动系统
pnpm dsh web
```

**性能对比**：
- `bcrypt` (C++): 超快，但需要编译
- `bcryptjs` (纯JS): 稍慢（约 2-3 倍），但无需编译，兼容性好

对于认证系统来说，bcryptjs 的性能完全够用（登录操作不频繁）。

## ⚠️ 常见问题

### Q1: 为什么不直接使用 bcryptjs？

**A**: `bcryptjs` 是纯 JavaScript 实现，速度比原生 bcrypt 慢 2-3 倍。但对于认证系统来说：
- ✅ 登录操作不频繁（每次登录慢 100-200ms 可以接受）
- ✅ 无需编译，兼容性极好
- ✅ API 完全兼容，无需修改其他代码
- ✅ 安全性相同（相同的算法）

**推荐**：开发环境使用 bcryptjs，生产环境（Linux 服务器）使用 bcrypt。

### Q2: npx @deepseek-ai/dsh 为什么找不到？

**A**: 因为构建失败了，`dsh` 命令没有安装。解决 bcrypt 问题后重新构建即可。

在此之前，使用完整路径：
```bash
./node_modules/.bin/dsh auth create-user admin admin123 --admin
```

### Q3: pnpm dsh web 失败怎么办？

**A**: 先确保构建成功：

```bash
# 检查构建状态
pnpm run build

# 如果成功，查看构建产物
ls -la packages/auth/auth-local/lib/

# 应该看到 index.js 和 types/ 目录
```

### Q4: 如何完全重置？

```bash
cd D:\File\VSCodeFile\QDHB\deepseek-harness

# 清理所有依赖
rm -rf node_modules
rm -rf packages/*/node_modules
rm -rf packages/*/*/node_modules

# 清理构建产物
rm -rf packages/*/lib
rm -rf packages/*/*/lib

# 重新安装
pnpm install
pnpm run build
```
