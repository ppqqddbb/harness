# 🚀 DeepSeek Harness 认证系统 - 立即开始

## 快速安装（推荐）

在 DeepSeek Harness 根目录执行：

```bash
# 1. 运行自动安装脚本
node packages/auth/setup.js

# 2. 安装依赖
pnpm install

# 3. 构建项目
pnpm run build

# 4. 创建管理员账号（使用脚本生成的密码或自定义）
npx @deepseek-ai/dsh auth create-user admin YOUR_PASSWORD --admin

# 5. 启动系统
pnpm dsh web
```

访问 http://127.0.0.1:3080 - 你会看到登录页面！

## ⚙️ 配置说明

认证系统通过 Cordis 配置启用。自动安装脚本会创建配置文件，或者你可以手动添加：

**配置文件位置**: 
- Windows: `C:\Users\你的用户名\.dsh\web\cordis.patch.yml`
- Linux/Mac: `~/.dsh/web/cordis.patch.yml`

**配置内容**:
```yaml
- insert:
    - id: auth-local
      name: '@deepseek-ai/dsh-auth-local'
      inject: [webServer, database]
      config:
        enabled: true              # 启用/禁用认证
        cookieName: dsh_session    # Cookie 名称
        sessionDuration: 604800    # 7天（秒）
        dbPath: auth.db           # 数据库路径
        bcryptRounds: 12          # 加密强度

    - id: cli-auth
      name: '@deepseek-ai/dsh-cli-auth'
      inject: [authLocal, commands]

    - id: ui-auth
      name: '@deepseek-ai/dsh-client-ui-auth'
```

## 📝 使用示例

### 创建用户
```bash
# 创建普通用户
dsh auth create-user alice mypassword

# 创建管理员
dsh auth create-user admin securepass --admin

# 自动生成密码
dsh auth create-user bob --admin
```

### 管理用户
```bash
# 查看所有用户
dsh auth list-users

# 修改密码
dsh auth change-password alice newpassword

# 删除用户
dsh auth delete-user bob
```

### 查看数据库
```bash
# Windows
sqlite3 C:\Users\你的用户名\.dsh\auth.db "SELECT * FROM auth_users;"

# Linux/Mac
sqlite3 ~/.dsh/auth.db "SELECT * FROM auth_users;"
```

## 🐛 常见问题

### Q: 无法创建用户？
A: 检查数据库文件权限，确认用户名不重复

### Q: 登录后立即退出？
A: 检查浏览器 Cookie 设置，确认服务器时间正确

### Q: 前端无登录页面？
A: 重新构建 `pnpm run build`，检查浏览器控制台

### Q: 忘记密码？
A: 使用 CLI 重置：`dsh auth change-password username newpassword`
