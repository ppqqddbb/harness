**数据库表结构**：
```sql
-- 用户表
CREATE TABLE auth_users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  is_admin INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL
)

-- 会话表
CREATE TABLE auth_sessions (
  id TEXT PRIMARY KEY,              -- 64字符随机hex
  user_id INTEGER NOT NULL,
  expires_at INTEGER NOT NULL,
  created_at INTEGER NOT NULL,
  FOREIGN KEY (user_id) REFERENCES auth_users(id) ON DELETE CASCADE
)
```

```typescript
// POST /api/auth/login

// POST /api/auth/logout

// GET /api/auth/me
```

### 数据流

**登录流程**：
```
1. 用户输入
   └─> 前端表单 (React)

2. HTTP 请求
   └─> POST /api/auth/login
       Body: { username, password }

3. 后端验证
   ├─> 查询用户：SELECT * FROM auth_users WHERE username = ?
   └─> 验证密码：bcrypt.compare(password, hash)

4. 创建会话
   ├─> 生成 session ID：randomBytes(32).toString('hex')
   └─> 存储：INSERT INTO auth_sessions

5. 设置 Cookie
   └─> Set-Cookie: dsh_session=<session-id>; HttpOnly; SameSite=Lax

6. 返回响应
   └─> { success: true, user: { username, isAdmin } }

7. 前端更新
   └─> 更新状态 → 显示主界面
```

**会话验证流程**：
```
1. 每次页面请求
   └─> 前端：GET /api/auth/me (包含 Cookie)

2. 后端解析
   ├─> 读取 Cookie：dsh_session
   └─> 查询数据库：
       SELECT u.* FROM auth_sessions s
       JOIN auth_users u ON s.user_id = u.id
       WHERE s.id = ? AND s.expires_at > NOW()

3. 返回结果
   ├─> 有效：{ authenticated: true, user: {...} }
   └─> 无效：{ authenticated: false }

4. 前端决策
   ├─> authenticated = true → 显示主界面
   └─> authenticated = false → 显示登录页
```
